SIH 2026 Jury Q&A Cheat Sheet: SatQuery AI

Read this to prepare for your presentation. It explains everything we built in simple, non-technical language.

Problem Statement: 26167 (ISRO/SAC)
Title: SatQuery AI: An Interactive Vision-Language Assistant for Multimodal Remote Sensing Image Analysis through Text Queries
Team: Antariksh Astra

1. The Problem & What Was Expected

The Core Problem: ISRO has massive amounts of satellite data (Optical from Cartosat, Radar/SAR from RISAT). Right now, to find something (like deforestation or illegal construction), highly trained experts have to use complex GIS software, manually align images, and write custom code. It is slow and difficult.

What ISRO Expected: An AI assistant where a non-expert can simply type or speak a question (e.g., "Are there new buildings here?") and the AI will analyze the satellite images, give a text answer, draw bounding boxes (visual grounding), and provide an "Execution Trace" (a log proving exactly how the AI made its decision).

2. What We Achieved

We built Drishti Spatial AI, a complete end-to-end platform:

  • Cinematic 3D UI: A military-style interactive 3D globe where you can speak to the AI.
  • Automated Agentic Pipeline: When you ask a question, the AI automatically finds the location, fetches the images (Cartosat/RISAT), and analyzes them.
  • Strict Audit Logging: We built an "Execution Trace" panel that shows JSON logs of the AI's thought process, ensuring 100% transparency for ISRO.

3. Our Tech Stack (What we used)

  • Frontend (UI): HTML5, CSS3, Vanilla Javascript, and Three.js (for the 3D spinning globe).
  • Backend (Logic): FastAPI (Python) for ultra-fast, asynchronous handling of queries.
  • Machine Learning (AI): PyTorch, Hugging Face Transformers, and the LLaVA-1.5 backbone.
  • Geocoding: Nominatim API to convert city names into latitude/longitude.

4. About the Model: The "Brain" of the AI

Q: Which model did you use and where did you get it?
We used LLaVA-1.5 (Large Language-and-Vision Assistant) as our base. It is an open-source model available on Hugging Face. It has 7 Billion parameters.
Q: Why this model and not ChatGPT (GPT-4) or Gemini?
ISRO deals with highly classified and sensitive satellite data. We cannot send ISRO data to closed, cloud-based APIs like OpenAI or Google. We chose LLaVA-1.5 because it is an open-weight model that can be downloaded and run locally and securely on our own private GPUs (air-gapped).
Q: Why did you use this approach instead of training from scratch?
Training a 7-Billion parameter model from scratch takes massive supercomputers and millions of dollars. Instead, we used a highly efficient technique called LoRA (Low-Rank Adaptation). LoRA allows us to take a pre-trained smart model and "fine-tune" it specifically for satellite data by only tweaking a tiny fraction of its brain (around 1-2% of the parameters).

5. Step-by-Step: How We Trained It & Improved Accuracy

Standard AI models are trained on normal photos (dogs, cats, cars taken from the ground). They perform poorly on satellite images because satellite images are taken from space (top-down view) and use different sensors (Radar/SAR). This is called the Domain Gap.

Here is step-by-step how we fixed it:

  1. Data Collection: We gathered specialized remote sensing datasets (VRSBench, RSVQA).
  2. Custom Encoders: We built specialized "eyes" for the model. For optical images (Cartosat), we added contrast-stretching. For Radar images (RISAT), we added speckle-filtering and decibel (dB) conversion so the AI could "see" SAR data properly.
  3. Domain Adaptation Layer: We added a "Sensor Prompt Conditioner." Before the AI answers, we inject a prompt telling it the exact sensor used (e.g., "This is a Cartosat-2S image with 0.65m resolution"). This drastically improved accuracy because the AI knew what scale it was looking at.
  4. LoRA Fine-Tuning: We trained the model on our custom satellite data to teach it how to answer remote sensing questions, ground objects (draw boxes), and detect changes over time.

6. Future Scope (What's Next?)

  • Edge Deployment (On-Orbit AI): Compressing this model (using Quantization) so it can run directly on the satellite's internal computer in space, beaming down only the answers instead of heavy images.
  • Multi-Agent Swarms: Having multiple specialized AI agents talk to each other (e.g., one expert in SAR, one in Optical, and one in Weather) to generate highly complex military/disaster reports.
  • Video Satellite Analysis: Analyzing real-time video feeds from geostationary satellites to track moving targets (ships, convoys) automatically.
